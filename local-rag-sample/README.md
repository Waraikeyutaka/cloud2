# 社内FAQボット（ローカル版のサンプル）

コマ5で、自分のローカルRAGが手元にない人が「棚卸し」に使うサンプルである。
架空の会社「カモメ物産」の社員が、社内の規程やFAQについて質問するためのボットという設定である。
文書（`docs/`）の内容はすべて架空である。

**このサンプルは実行しない。** 実行すると、埋め込みとチャットの API を何度も呼ぶ（共有の利用上限と教員の費用を消費する）。
コードを読むだけで棚卸しはできる。

## 作った人のメモ（ローカルで使っていたときの手順）

1. `.env.example` を `.env` にコピーし、自分のキーを書く
2. `pip install -r requirements.txt`
3. `python ingest.py` … `docs/` の文書を分割・埋め込みして `vector_store.json` に保存する
4. `python chat.py` … 質問を入力すると、関連する文書を探して答える（`exit` で終了）

文書を追加・修正したら、`python ingest.py` をもう一度実行する。
